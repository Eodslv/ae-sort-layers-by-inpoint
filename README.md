# ae-sort-layers-by-inpoint

After Effects JSX script that sorts layers by their in point.

## Features

- Default click: sorts layers from the latest in point to the earliest.
- Ctrl + click: sorts layers from the earliest in point to the latest.
- Sorts selected layers only when a selection exists; otherwise sorts every layer in the active composition.
- Keeps the original layer-panel order when layers have the same in point.

## Usage

1. Save or install `Sort_Layers_By_InPoint.jsx`.
2. Open the target composition in After Effects.
3. Run the script. For Motion Tools, use a regular click for reverse order and Ctrl + click for chronological order.

## 기능

- 기본 실행: 시작 시간이 늦은 레이어부터 위에 배치합니다.
- Ctrl + 실행: 시작 시간이 빠른 레이어부터 위에 배치합니다.
- 레이어를 선택한 경우 선택 레이어만, 선택하지 않은 경우 전체 레이어를 정렬합니다.
- 시작 시간이 같으면 기존 레이어 패널 순서를 유지합니다.

## 사용법

1. `Sort_Layers_By_InPoint.jsx` 파일을 저장하거나 설치합니다.
2. After Effects에서 대상 컴포지션을 엽니다.
3. 스크립트를 실행합니다. Motion Tools에서는 기본 클릭이 역순, Ctrl + 클릭이 정순입니다.

> 개인용으로 GPT를 사용하여 만들었으며 다른 환경에서 작동하지 않을 수 있습니다.
